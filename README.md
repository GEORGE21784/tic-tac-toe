# 🎮 Extended Tic-Tac-Toe (Connect-N)

A classic strategy game with a modern GUI implementation in Python using CustomTkinter.

## ✨ Key Features

- **Customizable ROWS*COLUMNS game board** with Connect-N winning condition
- **Modern dark-mode UI** with sleek hover effects
- **Complete game logic**:
  - Win detection (horizontal, vertical, and diagonal)
  - Automatic draw handling
  - Turn-based gameplay (O and X)
- **Quality-of-life features**:
  - Pop-up result notifications
  - Instant reset button
  - Move validation (prevents overwriting)

## 🛠️ Tech Stack

- Python 3.11.2
- Clean procedural programming approach
